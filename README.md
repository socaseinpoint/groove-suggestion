# Groove Suggestion Agent

> A crooked rhythm whisperer for producers who don't want to start with silence.

Groove Suggestion Agent is a minimal, offline tool that generates rhythmic patterns with human-like quirks, irregularity, and soul. It’s not for productivity. It’s for inspiration. You don’t need more perfect loops — you need **a broken pattern to begin with**.

This is not AI to replace you. It’s a creative partner that drops rhythmic seeds for your hands to shape.

---

## ✨ What It Does

- Generates MIDI grooves based on:
  - Style keyword (e.g., `glitch`, `idm`, `dusty`, `lofi`)
  - BPM and swing
  - Density: low / medium / high
- Adds randomness, groove drift, swing, ghost hits
- Outputs a `.mid` file + optional text layout

---

## 🛠️ Getting Started

### Requirements

- Node.js **or** Python (coming soon)
- Basic CLI or terminal access

### Install

```bash
git clone https://github.com/your-username/groove-suggestion-agent.git
cd groove-suggestion-agent
npm install
```

### Run it

```bash
node groove-agent.js --style glitch --bpm 90 --density low
```

It will generate a file like `glitch_groove_001.mid` in the `output/` folder.

You can also use the Telegram bot (coming soon).

---

## 🧠 Example Prompt to the Agent

```bash
groove-agent --style "glitchy idm" --bpm 93 --density low
```

Or just tell it:
> "Give me something twitchy and off-balance at 93 bpm with minimal hits"
